# IT 服务台与设备管理

## 服务台联系方式

IT 服务台提供三种报障渠道：内线电话 8888、邮箱 itsupport@nebula-tech.cn、企业微信「IT服务台」应用。企业微信渠道支持查看工单进度，推荐优先使用。

## 工单分级与响应时限

IT 工单按影响范围分为四级。P1 为全员性故障（如邮件系统整体不可用），15 分钟内响应、2 小时内解决或给出临时方案；P2 为部门级故障，30 分钟内响应、4 小时内解决；P3 为个人级故障，4 小时内响应、1 个工作日内解决；P4 为需求与咨询类，1 个工作日内响应并纳入排期。

## 设备报修

设备故障须先建工单再送修，未经工单登记的维修费用不予报销。需寄外维修的设备（如主板损坏）寄修周期为 5 至 7 个工作日，期间可向 IT 服务台申请备用机，备用机借用期最长 14 天，到期归还。

## 打印与耗材

打印统一通过刷工卡放行。打印收费标准：黑白 0.1 元/页，彩色 0.5 元/页；每名员工每月有 100 页免费额度，超出部分计入部门成本。批量打印 200 页以上的材料须提前向行政部申请，避免占用公共设备。

## 软件安装

办公软件由 IT 统一推送安装。因业务需要安装非标准软件的，须在工单中说明用途，经 IT 安全员审核后由服务台协助安装，员工不得自行下载安装来源不明的软件。
