# 投诉处理与升级机制

## 首问负责制

客户投诉实行首问负责制：第一受理人须在 24 小时内给出处理方案，并跟进至问题关闭，不得以非本职范围为由推诿。受理人离岗时须完成交接并由接手人确认。

## 投诉分级

一般投诉由客服主管在 3 个工作日内处理完毕；重大投诉（媒体曝光、监管投诉、同一事件 5 人以上群体投诉）须在 2 小时内上报客服总监与公关部，由客服总监牵头成立专项小组处理。

## 回访与满意度

投诉解决后 48 小时内进行电话回访，满意度采用 5 分制记录。回访低于 3 分的重新开单并升级一级处理；季度满意度低于 4 分的客服专员须参加服务复盘培训。

## 客服热线

客服热线为 400-880-6633，服务时间每日 09:00 至 21:00；投诉专线为 400-880-6635，工作日 09:00 至 18:30 接听。企业微信客服号工作日 09:00 至 18:00 在线。

## 服务红线

客服人员服务红线：不得与客户发生争执或使用刺激性别表达；不得承诺制度之外的赔偿或补偿；不得泄露客户个人信息与交易记录；不得私自添加客户个人社交账号处理业务。触犯红线的视情节给予警告直至解除劳动合同。
